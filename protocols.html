📘 study notes: routing protocols

1. Routing Protocol Categories

  • Distance Vector: RIP, IGRP. Uses hop count, sends full routing table to neighbors periodically. Slow convergence, prone to loops.
  • Link State: OSPF, IS-IS. Builds a complete topology map, uses Dijkstra's SPF algorithm. Fast convergence, scalable.
  • Hybrid/Advanced Distance Vector: EIGRP. Uses DUAL algorithm, supports unequal cost load balancing, very fast convergence.
  • Path Vector: BGP. Used between autonomous systems, uses path attributes and AS-path for loop prevention.

2. Key Metrics

  • RIP: Hop count (max 15, 16 = unreachable)
  • OSPF: Cost based on bandwidth (10^8 / bandwidth)
  • EIGRP: Composite metric (bandwidth, delay, load, reliability, MTU)
  • BGP: Path attributes (AS-path, local preference, MED, weight)

3. Administrative Distance (Cisco)

  • Connected: 0
  • Static: 1
  • EIGRP: 90
  • OSPF: 110
  • RIP: 120
  • External BGP: 20
  • Internal BGP: 200

4. Convergence & Timers

  • RIP timers: Update 30s, Invalid 180s, Hold-down 180s, Flush 240s
  • OSPF timers: Hello 10s, Dead 40s (broadcast networks)
  • EIGRP timers: Hello 5s, Hold 15s
  • Convergence: State where all routers have consistent network topology

5. Route Selection Order

  • Longest prefix match first (most specific route wins)
  • Then lowest administrative distance
  • Then lowest metric

6. Protocol Selection Guide

  • Small networks (<15 hops): RIP is simple and sufficient
  • Enterprise networks: OSPF or EIGRP for scalability
  • ISP / Internet: BGP for inter-domain routing
  • Cisco-only environments: EIGRP offers best performance
  • Multi-vendor: OSPF is the open standard choice
